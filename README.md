# Bienmind

Site vitrine de Bienmind - Editeur de services SaaS pour le bien-etre et la qualite de vie au travail.

## Structure du projet

```
bienmind/
├── index.html      # Page principale
├── css/
│   └── styles.css  # Styles personnalises
├── js/
│   └── main.js     # Scripts JavaScript
└── README.md
```

## Technologies utilisees

- HTML5
- CSS3 avec Tailwind CSS (CDN)
- JavaScript vanilla
- Google Fonts (Inter)

## Fonctionnalites

- Design responsive et moderne
- Animations fluides au scroll
- Navigation fixe avec effet de transparence
- Formulaire de contact avec validation
- Section hero avec illustration SVG animee
- Presentation des services SaaS
- Temoignages clients
- Section a propos avec valeurs

## Lancement local

Ouvrir simplement `index.html` dans un navigateur web.

## Sections du site

1. **Hero** - Presentation principale avec statistiques cles
2. **Services** - 6 solutions SaaS pour le bien-etre
3. **Fonctionnalites** - Avantages de la plateforme avec dashboard demo
4. **A propos** - Mission, valeurs et chiffres cles
5. **Temoignages** - Retours clients
6. **Contact** - Formulaire de demande de demo
