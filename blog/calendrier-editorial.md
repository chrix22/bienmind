## Métriques et Objectifs

### KPIs par article
- **Objectif trafic** : 500 vues / article dans les 30 premiers jours
- **Temps de lecture** : > 5 minutes en moyenne
- **Taux de scroll** : > 70%
- **Partages sociaux** : > 20 par article
- **Inscriptions newsletter** : > 2% de conversion

### SEO
- Chaque article cible 3-5 mots-clés principaux
- Optimisation title/meta description
- Maillage interne entre articles
- Backlinks vers la page principale Bienmind

### Distribution
- **LinkedIn** : Publication + commentaires
- **Twitter/X** : Thread résumant les points clés
- **Newsletter** : Envoi hebdomadaire (3-4 articles)
- **Republication** : Medium, Dev.to pour les articles techniques

## Templates

### Structure article type (1500 mots)
1. **Introduction** (150 mots) - Accroche + problème + promesse
2. **Sommaire** - Navigation cliquable
3. **Section 1** (250 mots) - Contexte / Définitions
4. **Section 2** (300 mots) - Le coeur du sujet
5. **Section 3** (300 mots) - Applications pratiques
6. **Section 4** (250 mots) - Guide étape par étape
7. **Section 5** (150 mots) - Outils et ressources
8. **Conclusion** (100 mots) - Résumé + CTA

### Éléments visuels
- Tableau comparatif (si applicable)
- Infographie ou schéma (1 minimum)
- Screenshots / captures d'écran
- Code snippets (articles techniques)
- Citations encadrées

## Notes de rédaction

### Ton éditorial
- Professionnel mais accessible
- Pas de jargon non expliqué
- Exemples concrets et actionnables
- Perspective "bien-être au travail" quand pertinent

### Sources
- Privilégier les sources primaires (papers, docs officielles)
- Citer les études et statistiques
- Lier vers les outils mentionnés

### Mises à jour
- Revoir les articles techniques tous les 3 mois
- Mettre à jour les comparatifs lors de nouvelles versions
- Ajouter un bandeau "Mis à jour le XX" si nécessaire
